# Product Import Script

This script automates the bulk import of products from JSON files into your MongoDB database.

## Prerequisites

1. Ensure your MongoDB database is running
2. Place your `final_products_img.json` file in the project root directory
3. Make sure your `.env` file has the correct `MONGODB_URI` configured

## Usage

### Method 1: Using npm script (Recommended)
```bash
cd backend
npm run import-products
```

### Method 2: Direct execution
```bash
cd backend
node scripts/importProducts.js
```

### Method 3: Custom file path
```bash
cd backend
node scripts/importProducts.js /path/to/your/products.json
```

## What the script does

1. **Validates** the JSON file structure
2. **Connects** to your MongoDB database
3. **Transforms** data to match your Product model format
4. **Checks** for existing products (skips duplicates)
5. **Imports** products in batches for optimal performance
6. **Reports** progress and results

## Expected JSON Format

Your JSON file should contain an array of product objects with the following structure:

```json
[
  {
    "_id": "unique-id",
    "name": "Product Name",
    "modelNumber": "MODEL-123",
    "description": "Product description",
    "price": 25000,
    "category": "Solar Water Heaters",
    "specifications": {
      "power": "100W",
      "efficiency": "85%",
      "warranty": "5 years"
    },
    "quantity": 50,
    "reorderLevel": 10,
    "imageUrls": ["url1", "url2"]
  }
]
```

## Features

- ✅ **Duplicate Prevention**: Skips products with existing names or model numbers
- ✅ **Batch Processing**: Processes products in batches for better performance
- ✅ **Data Transformation**: Automatically handles different data formats
- ✅ **Progress Tracking**: Shows real-time import progress
- ✅ **Error Handling**: Continues processing even if some products fail
- ✅ **Validation**: Checks required fields before import
- ✅ **Summary Report**: Provides detailed results after completion

## Troubleshooting

### Common Issues

1. **Database Connection Error**
   ```bash
   ❌ MongoDB connection failed: connect ECONNREFUSED 127.0.0.1:27017
   ```
   - Solution: Ensure MongoDB is running and MONGODB_URI is correct

2. **File Not Found**
   ```bash
   ❌ File not found: /path/to/file.json
   ```
   - Solution: Check file path and ensure the JSON file exists

3. **Validation Errors**
   ```bash
   ⚠️  VALIDATION ERRORS:
   - Product 1: Missing name
   ```
   - Solution: Fix the data in your JSON file and try again

4. **Permission Errors**
   - Solution: Ensure you have read/write permissions for the database and files

### Support

If you encounter any issues:
1. Check the error messages for specific details
2. Verify your JSON file format matches the expected structure
3. Ensure your database connection is working
4. Review the MongoDB logs for additional information

## Notes

- The script will NOT delete or update existing products
- Products are matched by name OR model number for duplicate detection
- **Fresh ObjectIds are automatically generated by MongoDB** (existing `_id` values in JSON are ignored)
- Image URLs are flattened if they're in nested arrays
- Invalid specifications JSON strings are converted to empty objects
- Default values: quantity=50, reorderLevel=10 (if not provided)
