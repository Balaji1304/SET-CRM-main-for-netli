# 🚀 Quick Start: Import Products to MongoDB

This guide will help you import all products from `final_products_img.json` into your MongoDB database automatically.

## 📋 Step-by-Step Instructions

### Step 1: Place the JSON file
Make sure your `final_products_img.json` file is in the **root directory** of your project (same level as this file).

### Step 2: Open Terminal
Open your terminal/command prompt and navigate to your project directory.

### Step 3: Run the Import
Execute one of these commands:

**Option A - Simple command:**
```bash
cd backend
npm run import-products
```

**Option B - With custom file path:**
```bash
cd backend
node scripts/importProducts.js /path/to/your/final_products_img.json
```

### Step 4: Monitor Progress
The script will show you:
- ✅ Products being created
- ⏭️ Products being skipped (if duplicates)
- 📊 Final summary with counts

## ⚡ Expected Output

You should see something like:
```

✅ MongoDB connected successfully
🆔 Fresh ObjectIds will be generated by MongoDB for all new products.
📊 Found 18 products to import

✅ Created product: SUNLIT COPPER ETC 100 LPD | ID: 676b1234567890abcdef0002 (2/18)
```

## 🔧 Prerequisites

1. **MongoDB Running**: Make sure your MongoDB database is running
2. **Environment**: Your `.env` file should have correct `MONGODB_URI`
3. **Dependencies**: Run `npm install` in the backend folder if needed

## 🚨 Important Notes

- **Safe Operation**: Existing products won't be duplicated
- **Fresh ObjectIds**: MongoDB automatically generates new ObjectIds (existing `_id` values are ignored)
- **Batch Processing**: Products are imported in batches for optimal performance
- **Error Handling**: Script continues even if some products fail
- **No Data Loss**: Your existing data remains safe

## 📁 File Structure Expected

```
your-project/
├── final_products_img.json          ← Your product data file
├── backend/
│   ├── scripts/
│   │   └── importProducts.js        ← The import script
│   └── package.json
└── PRODUCT_IMPORT_INSTRUCTIONS.md   ← This file
```

## 🆘 Troubleshooting

**If you get errors:**

1. **"File not found"** → Check file path and location
2. **"MongoDB connection failed"** → Ensure MongoDB is running
3. **"Validation errors"** → Check your JSON file format

**Need help?** Check the detailed README at `backend/scripts/README.md`
